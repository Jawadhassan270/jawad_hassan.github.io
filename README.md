# Jawad Hassan — Engineering Portfolio

A simple responsive personal portfolio prepared for GitHub Pages.

## Before publishing
Open `index.html` and replace:
- `YOUR_EMAIL`
- `YOUR_LINKEDIN_URL`
- `YOUR_GITHUB_URL`
- `YOUR_CV_URL`

You can also replace the graphic project headers with your own CAD/render images later.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your site will be available at `https://YOURUSERNAME.github.io` after deployment.
